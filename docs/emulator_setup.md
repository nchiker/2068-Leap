# Emulator setup

The maintained emulator guide for the current system, **2068-Leap V2**, is
[`docs/v2/EMULATOR_SETUP.md`](v2/EMULATOR_SETUP.md): ZEsarUX (the qualification
emulator, with its required EXROM-mirroring patch), EightyOne and Fuse
(courtesy), and the TSRun browser emulator, with the V2 release file names.

EightyOne's step-by-step configuration is also in
[`eightyone_setup.md`](eightyone_setup.md).

The Release 1 Beta (V1) version of this page, with the V1 file names and
extensions, is kept with the V1 source on the `main` branch:
[`main:docs/emulator_setup.md`](https://github.com/nchiker/2068-Leap/blob/main/docs/emulator_setup.md)
(see [`V1_LEGACY.md`](V1_LEGACY.md)).
