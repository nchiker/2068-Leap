## 1. What changed from v2.0.0-emu.1

* **`BEEP seconds,semitones`** -- Sinclair's syntax, played on the AY-3-8912's channel A (was raw cycle/delay counts on the loudspeaker). Fractional seconds, rounded to display frames; semitones -60..69, a fraction cut off, below -39 plays 27.5 Hz; error 15 out of range; channel A left silent, B and C untouched; interrupts stay on and BREAK stops a note.
* **`SOUND` accepts register 0** (0..16, as the stock TS2068 BASIC).
* **Startup chime** kept, with the same register writes at the same frames (regenerated by code).
* **`PAUSE` rollover defect fixed (M-PAUSE):** `PAUSE n` could end at once when the frame counter passed 65535 during the pause. `PAUSE`, `BEEP` and the chime now share one `HALT`-counting frame wait.
* **Optional cbeep package** (`LOAD "CBEEP" EXT`, 260 bytes): `CBEEP milliseconds,semitones,border` on the TS2068's loudspeaker, with V2's original beeper routine. Package ABI unchanged (2.0); the five original packages are byte-identical.
* Documentation: the user manual (Markdown and the regenerated Word edition), language reference, defect register, package ABI, hardware checklist. Studies: `V2_AY_BEEP_STUDY.md`, `V2_CLASSICBEEP_STUDY.md`.

## 4. Known limitations (documented)

* Not hardware-qualified (above).
* With the frame interrupt switched off by a program, `PAUSE` never ends (as in the release) and `BEEP` never ends when the interrupt is inhibited at port `$FF` (M-3; manual `BEEP`, `PAUSE`).
* `CBEEP`: interrupts are off while it sounds, so BREAK waits for the note; it needs the border colour as an argument and changes the border to it; loading it replaces any other package (one at a time).
* The emulator runs 50 frames a second and a 0.5 % fast AY clock; a TS2068 runs 60 (not measured).
* Open from the release, unchanged: Q-24, Q-26, RC-O1 to RC-O7, T-3; new test debt T-4 (`V2_DEFECT_REGISTER.md`).
